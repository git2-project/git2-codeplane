# Codeplane version notes — 2026-11-03

**Audience:** Dash (dash-api, code browser), CI (ci-svc), and their coding agents.
**Scope:** git-svc can now read repository content over gRPC: branches, tags, directories, files and commits with their diffs. This backs dash-api's code-browsing endpoints (WBS-6.1) and lets ci-svc read `.git2-ci.yml`.

**Canonical reference:** [proto/git/v1/commit.proto](../../../../proto/git/v1/commit.proto), [proto/git/v1/ref.proto](../../../../proto/git/v1/ref.proto) and [ADR 0013](../../../decisions/0013-reading-repository-content.md).
These are the source of truth; this note only summarizes the change.

**Breaking?** No. Two new services; nothing existing changed.

---

## 🟢 NEW — `RefService` and `CommitService` (for Dash)

Same port and conventions as `RepositoryService` (`:9090`, repository by ID, no authorization in git-svc).

| dash-api endpoint | git-svc RPC | Notes |
|---|---|---|
| `GET /branches` | `RefService.ListBranches` | default branch first, then by name; `query` filters case-insensitively |
| `GET /tags` | `RefService.ListTags` | newest first; `message` set for annotated tags |
| `GET /tree` | `CommitService.GetTree` | one directory, directories first; `empty: true` for a repository without commits; `last_commit` of the directory |
| `GET /blob` | `CommitService.GetBlob` | up to 1 MiB (`truncated` beyond); `binary` files come without content; `lfs` for LFS pointers |
| `GET /raw` | `CommitService.GetRawBlob` | server stream: size and name in the first message, then the bytes |
| `GET /commits` | `CommitService.ListCommits` | newest first; optional `path`; paging |
| `GET /commits/{sha}` | `CommitService.GetCommit` | full SHA or prefix ≥ 7; diff against the first parent |

**`ref`** is a branch, a tag, `refs/heads/…`, `refs/tags/…` or a full SHA; empty means the default branch. A branch wins over a tag of the same name. Every answer returns the commit it read: build links from it.

**Errors:**

| Code | When |
|---|---|
| `INVALID_ARGUMENT` | bad ID, ref, path, sha or page token; a file asked as a directory (or the reverse); a submodule |
| `NOT_FOUND` | the repository, ref, path or commit does not exist (messages: `repository not found`, `ref not found`, `path not found`, `commit not found`) |

**Limits** (see the ADR): 10 000 entries per directory, 1 MiB per file for display, 300 files per commit diff, patches cut at 64 KiB per file and 1 MiB per commit.

**What dash-api fills itself:** `Blob.language` (from the file name), `Signature.user` (from the email) and `Branch.protected` (false until WBS-7.1).

**Try it in the devcontainer** after pushing to a repository (see the 31 Oct note):

```sh
go tool -modfile=tools.mod grpcurl -plaintext -d '{"repository_id":"<repo-id>"}' \
  localhost:9090 git.v1.CommitService/GetTree
```

## 🟢 NEW — Reading `.git2-ci.yml` (for CI)

`CommitService.GetBlob` with `ref` = the pushed commit's SHA and `path` = `.git2-ci.yml` returns the file (`NOT_FOUND` with `path not found` when the commit has none). This is the read assumed in A-03.
